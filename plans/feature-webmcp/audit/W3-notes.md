## Boundaries

- Uses context.query and exactly the existing UI query references: listSummariesByUser, getDetail, getAllSessionsWithBikes, getReportV2, getMyProfile, getAccess.
- All outputs are explicit field projections. User documents, contact fields, questionnaire responses, notes, payment/subscription identifiers, photos and download capabilities are omitted.
- Report measurements come from the authorized query. Detailed headings reuse the UI mapper/localized parameter copy only when source.access.fullReport is true. Missing recommendations return not_generated and never trigger generation.
- Access state comes from productId, independent of open enforcement, and expiry is returned from getAccess without a separate subscription read.
- Bike/session names are bounded and marked untrusted. Lists paginate over the existing complete UI query; database work itself is not newly paginated. If a requested output exceeds 16,000 characters, the foundation returns LIMIT_EXCEEDED without a misleading cursor.
- Profile navigation opens `/profile`, where the rider can open the measurement editor. W1's stable contract disallows navigation query parameters, so the provisional edit deep link from the spec is not used. Navigation uses fixed locale-aware destinations, no inputs, and never submits a form.
